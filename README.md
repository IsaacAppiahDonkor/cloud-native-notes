## Welcome!

This repos introduces beginners to Cloud Native applications. 
It contains a simple app written in Python that would be deployed on Kubernetes. 
The aim is to spark your curiosity and introduce you to thinking like an engineer.

Feel free to fork and star this repo.

---
Here are the topics organized by weeks.

- *Week 1* - Are You Ready?
- *Week 2* - Containers and Images
- *Week 3* - Kubernetes Core Objects
- *Week 4* - Configuration, Secrets and Storage
- *Week 5* - Basic Troubleshooting 
- *Week 6* - Networking and Ingress
- *Week 7* - Observability
- *Week 8* - GitOps with ArgoCD


**Happy learning and building!**
